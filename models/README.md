# نموذج فكّ الالتواء (UVDoc)

هذا المجلد يحتوي نموذج `uvdoc.onnx` المستخدم في تصحيح التواء صور
الموبايل قبل OCR.

**الملف غير مرفوع إلى git** (30 ميجا). يُنزّله البوت تلقائيًا عند أول
حاجة إليه، ويتحقّق من بصمة `SHA256` المثبّتة في الكود قبل استخدامه.

## التنزيل اليدوي (اختياري)

لو أردت تنزيله مسبقًا (مثلًا لصورة Docker بلا شبكة وقت التشغيل):

```bash
mkdir -p models
curl -L -o models/uvdoc.onnx \
  https://huggingface.co/PaddlePaddle/UVDoc_onnx/resolve/main/inference.onnx
```

## تعطيله

فكّ الالتواء **اختياري تمامًا** — البوت يعمل بدونه ويتراجع بهدوء إلى مسار
tesseract المباشر:

```env
OCR_DEWARP=0
```

أو على أندرويد (لا `onnxruntime`) يُتخطّى تلقائيًا.

# إعداد Wispbyte (خطوتان)

## ١) Startup Command — انسخ هذا السطر حرفيًا

```
python main.py
```

> لا تكتب `bash setup.sh`: بعض صور Wispbyte بلا bash فتفشل. و`main.py` يفعل
> الشيء نفسه ببايثون الصافي — يثبّت الحاجيات بلا root ثم يشغّل البوت.

## ٢) Variables — أضف هذه الثلاثة (تبويب Startup ← Variables)

| المتغيّر | من أين تجيبه |
|---|---|
| `BOT_TOKEN` | @BotFather |
| `OWNER_ID` | @userinfobot (آيدي حسابك) |
| `STORAGE_CHANNEL` | آيدي قناتك، يبدأ بـ `-100` |

اختياري لكن مفيد:

| المتغيّر | القيمة | لماذا |
|---|---|---|
| `DATABASE_URL` | `postgresql+asyncpg://…` | Wispbyte يمسح القرص عند كل إعادة نشر — SQLite تضيع |
| `AI_API_KEY` | مفتاحك | بدون مفتاح: رسالة عربية واضحة، بلا مخرجات مزيفة |
| `ZAKR_MINIMAL` | `1` | لو مساحة القرص ضيّقة (يوفّر حزمًا غير ضرورية) |

## ٢.٥) المتغيّرات المهمّة (بالترتيب)

| المتغيّر | لماذا | الافتراضي |
|---|---|---|
| `DATABASE_URL` | **الأهم**: Wispbyte يمسح القرص عند كل إعادة نشر ⇒ SQLite تضيع (المستخدمون والملفات والإعدادات). قاعدة خارجية (Supabase/Neon مجانًا) تحفظ كل شيء | SQLite (مؤقت) |
| `ZAKR_MINIMAL` | `1` = وضع اقتصادي على لوحة ضيّقة المساحة/الذاكرة | تلقائي |
| `ZAKR_MEMORY_MB` | لوحة لا تضع `SERVER_MEMORY` — أخبر البوت بحدّك | تلقائي |

### ماذا يفحص البوت عند الإقلاع؟

يكتب في السجل نتيجة كل فحص، وكل تحذير يقول **السبب والحلّ**:

```
⚠️ قاعدة البيانات SQLite على قرص **يُمسح** عند كل إعادة نشر.
   الحلّ: أضف DATABASE_URL لقاعدة خارجية …

⚠️ حدّ الذاكرة على اللوحة 384 MB — أقلّ من المطلوب لتشغيل مريح.
   البوت يستهلك ~200 MB وحده …
```

### قراءة الصور على Wispbyte — **لا تحتاج أي صلاحية**

هذه كانت أصعب ميزة على اللوحات: `tesseract` حزمة نظام تحتاج root، واللوحة
لا تعطيه. لذلك صار المسار مختلفًا تمامًا:

- **لا تثبيت نظام إطلاقًا.** `PyMuPDF` يحوّل صفحات PDF إلى صور داخل بايثون.
- الصور تُرسل إلى **وكيل الرؤية الذي يختاره المستخدم** بمفتاحه هو
  (OpenAI · Gemini · Anthropic · Azure · xAI · OpenRouter).
- لا `apt`، لا `root`، لا انتظار تنزيل ١٦٠ ميجا في الخلفية — أسرع إقلاع.

**الثمن بصراحة:** لو المستخدم لم يحفظ مفتاح وكيل يدعم الصور، فالملفات
المصوّرة **لا تُقرأ** (لا بديل في البوت). ملفات PDF النصّية تُقرأ عادي في
كل الأحوال، والرفع لا يفشل أبدًا لأجل ذلك.

## ٣) إن فشل شيء

- **`BOT_TOKEN غير مُعدّ`** ← لم تحفظ المتغيّرات أو لم تُعد التشغيل بعد الحفظ.
- **`الملف مصوّر — لا أستطيع قراءة نصه`** ← المستخدم لم يحفظ مفتاح وكيل
  يدعم الصور. الحلّ: ⚙️ إعدادات الذكاء الاصطناعي ← أضف مفتاح OpenAI/Gemini
  ← أعد رفع الملف. (الملف نفسه يُرفع ويُنزَّل عادي في كل الأحوال.)
- **`حزم أساسية لا تُستورد`** ← مساحة القرص أو الشبكة. أعد التشغيل؛ التثبيت
  يبدأ من حيث توقّف (pip يخزّن ما نجح).

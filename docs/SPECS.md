## ٣) التقنيات

| الطبقة | التقنية | ملاحظة |
|---|---|---|
| اللغة | Python **3.11+** (مُختبَر على 3.13) | بلا إطار ويب |
| إطار البوت | aiogram **3.31** | async بالكامل |
| قاعدة البيانات | SQLAlchemy **2.1** (async) + Alembic | SQLite افتراضيًا · PostgreSQL للكلاود |
| قراءة PDF | pypdf 7 | استخراج نص + صور |
| OCR | tesseract **5.5** + poppler | لغات `ara` · `eng` · `osd` |
| فكّ الالتواء | UVDoc على ONNX Runtime | نموذج ٣١ ميجا — لصور الموبايل المائلة |
| بحث دلالي | TF-IDF محلي (جوه البرنامج) | **يعمل بلا إنترنت** |
| بحث نصي | FTS5 (SQLite) / tsvector+GIN (Postgres) | tokenize = trigram |
| التخزين | قناة/جروب تيليجرام | الملفات **ليست على السيرفر** |
| النشر | VPS · دوكر · Railway · systemd | ٤ طرق جاهزة |

### اختياري (٢١ متغيّرًا موثّقًا في `.env.example`)

> ⚙️ **قاعدة ذهبية:** البوت **يعمل كامل بلا مفتاح ذكاء اصطناعي** — ميزات الـAI تختفي بهدوء، والباقي شغّال.

## ٨) الموثوقية والأمان

| البند | الوضع |
|---|---|
| **اختبارات** | ١٢ ناجحة · ٠ فاشلة · ٠ متخطّاة |
| **فحص ثابت** | `ruff` (F,E9,W6) نظيف · `vulture` نظيف · `compileall` سليم |
| **المفاتيح** | لا تُعرض كاملة ولا تُسجّل أبدًا · الرسائل تُحذف فورًا · `.env` صلاحيته **600** |
| **سجل تدقيق** | من غيّر ماذا وامتى (الاسم + الوقت + القيمة القديمة/الجديدة) |
| **التحقّق قبل التشغيل** | توكن غير صالح ⇒ رسالة عربية واضحة بدل انهيار صامت |
| **الإغلاق النظيف** | المحرك يُغلق ويُفرَّغ عند التوقف (لا اتصالات معلّقة) |
| **فحص الصحة** | نبضة حياة + `HEALTHCHECK` في دوكر (بوت متجمّد يُعاد تشغيله) |
| **الترقية** | `alembic upgrade head` ينتج قاعدة كاملة (مُختبَر: ٠ جدول ناقص) |
| **التثبيت** | `python main.py` بأمر واحد على أي منصّة · بلا root · آمن للتكرار · لا يستبدل `.env` موجود |

## ٩) التشغيل — ٤ طرق

| الطريقة | الأمر | مناسب لـ |
|---|---|---|
| **أمر واحد** ⚡ | `python main.py` | أي حد وأي منصّة — يعمل التثبيت كله بلا root |
| VPS + systemd | `bash setup.sh --systemd` | خدمة ٢٤ ساعة |
| دوكر | `./setup.sh --docker` | عزل وتكرار سهل |
| Railway | رفع + `railway.toml` | بلا سيرفر (مع PostgreSQL خارجي) |

**الحد الأدنى للتشغيل:** بايثون 3.11 + ٢٥٠ ميجا رام + اتصال إنترنت. القاعدة SQLite تكفي مكتبة متوسطة؛ وللكلاود PostgreSQL (Supabase، منفذ **5432**).

## ١٠) ما لا يفعله (بصراحة)

| غير مدعوم | السبب / البديل |
|---|---|
| ملفات أكبر من ٢٠ ميجا | حدّ تيليجرام — الحل: سيرفر Bot API محلي عبر `BOT_API_BASE` |
| موقع أو تطبيق موبايل | البوت **هو** الواجهة |
| مكالمات صوتية أو فيديو | بلا وسائط متحركة |
| قراءة PDF مكتوب بخط يدوي سيئ | OCR يتعامل مع المطبوع أساسًا |
| نسخ احتياطي سحابي تلقائي | نسخ محلية — ارفع مجلد `backups` بنفسك |
| تعدد نسخ البوت (Replicas) | Long Polling = نسخة واحدة فقط |
| بحث عربي متقدّم (جذور/صرف) | بحث كلمات + trigram + دلالي — لا تحليل صرفي |

## ١١) الخلاصة في سطرين

بوت تيليجرام **عربي بالكامل** يجمع ملفات الدراسة ويبحث جواها بالكلمة والمعنى، ويشرح ويلخّص ويولّد امتحانات بـ**٢٢ مزوّد ذكاء اصطناعي** يُدار كله من داخل البوت، ويشتغل **بلا سيرفر** (التخزين على تيليجرام)، ويتثبّت **بأمر واحد** — مع ٥٨٣ اختبارًا تثبت أنه يعمل.

# نقاط تشغيل بوت ذاكر

## الواجهات الرئيسية

`setup.sh` و`setup.py` هما واجهتا الإعداد والتشغيل المدعومتان. كل ملف منهما مسؤول عن دورة التجهيز: فحص Python، تجهيز البيئة، تثبيت الاعتماديات المطلوبة للمنصة، قراءة `.env` ومتغيرات الاستضافة، التحقق من القيم، ثم إجراء الفحص الذاتي. لا يبدأ التطبيق إذا فشل شرط أساسي.

بعد نجاح التجهيز، يستدعي كل Setup ملف `main.py`. هذا الملف ليس بديلًا عن Setup في النشر المعتاد؛ بل هو مرحلة الإقلاع التالية التي تتأكد من حالة التجهيز ثم تشغّل `bot.main`.

## الأوامر

- Linux / Wispbyte: `bash setup.sh --wispbyte`
- Python: `python setup.py --wispbyte`
- تشغيل عادي: `bash setup.sh --start` أو `python setup.py --start`
- تجهيز دون تشغيل: `--no-start`
- فحص دون تثبيت: `--check`

## الإعدادات

المتغيرات الإلزامية: `BOT_TOKEN`, `OWNER_ID`, `STORAGE_CHANNEL`. تُقرأ متغيرات لوحة الاستضافة أولًا، ثم `.env` كقيمة افتراضية. عند وجود stdin تفاعلي، يحاول Setup طلب القيم الناقصة أو غير الصالحة. إذا لم تمرّر لوحة الاستضافة الإدخال إلى العملية، فلا يمكن للبرنامج فرض إدخال مباشر؛ عندها يجب تعريف القيم في Startup → Variables.

## ملاحظات تشغيل

- لا تشغّل `bot.main` مباشرةً؛ لأنه يتجاوز التثبيت والتحقق.
- لا تستخدم `python setup.sh`؛ شغّل Bash بالأمر `bash setup.sh`.
- لا تحذف `main.py`؛ ملفات Setup تستدعيه بعد نجاح التجهيز.
- لا تضع التوكنات أو مفاتيح الخدمات في README أو ملفات التوثيق أو سجلات التشغيل.

## 3) الصلاحيات

| الصلاحية | التصفّح | التحميل | الرفع | مراجعة | إدارة مواد | إدارة مستخدمين | حذف نهائي |
|---|---|---|---|---|---|---|---|
| **طالب** | ✅ | ✅ | ✅ | — | — | — | — |
| **مشرف** | ✅ | ✅ | ✅ | ✅ | ✅ | — | — |
| **أدمن** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ (ترقية لمشرف) | ✅ |
| **المالك** | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ (كل شيء) | ✅ |

**القواعد الثابتة:**
- الدخول مفتوح: أي مستخدم تيليجرام يُسجَّل **طالبًا** تلقائيًا عند أول تفاعل.
- المالك يُحدَّد بـ `OWNER_ID` ويُرقَّى تلقائيًا، **ولا يمكن تنزيته أو حظره**.
- الأدمن يرقّي لمشرف فقط؛ ترقية الأدمن للمالك وحده.
- المستخدم المحظور لا تصله أي استجابة عدا رسالة الحظر.

## 4) سياسة المحتوى

| الحالة | المعنى | من يراها |
|---|---|---|
| `pending` | بانتظار المراجعة | الرافع + المشرفون |
| `approved` | منشور | الجميع |
| `rejected` | مرفوض | الرافع + المشرفون |
| `deleted` | محذوف (حذف ناعم) | المشرفون فقط |

- **المراجعة إلزامية افتراضيًا** (`REQUIRE_REVIEW=true`) — يمكن تعطيلها للنشر الفوري.
- **النقاط تُمنح عند الموافقة** لا عند الرفع (لمنع إغراق المكتبة).
- **حذف ناعم**: السجل يبقى للتدقيق، ويُحذف المنشور من قناة التخزين.
- **سجل تدقيق**: كل إجراء (قبول/رفض/حذف/ترقية/حظر) يُسجَّل في `moderation_log`.
- **كشف التكرار**: عمود `sha256` مفهرس لمقارنة الملفات المتطابقة.
- **النسخ الاحتياطي**: تلقائي كل 12 ساعة + زر يدوي + تدوير لآخر 14 نسخة.

## 4.5) مرجعية الإعدادات (مهم)

**اللوحة تتحكم، و`.env` هو القيمة الافتراضية فقط.**

| الإعداد | أين يُقرأ | الأثر |
|---|---|---|
| `require_review` | الداتابيز ← .env | هل ينتظر الملف موافقة مشرف |
| `points_upload` | الداتابيز ← .env | نقاط الرفع عند الموافقة |
| `download_cost_points` | الداتابيز ← .env | تكلفة التحميل (0 = مجاني) |
| `maintenance` | الداتابيز | حظر الطلاب وإتاحة البوت للمشرفين فقط |
| `welcome_message` | الداتابيز | نص الترحيب في /start |
| `bot_name` | الداتابيز | اسم البوت المعروض |
| `OWNER_ID`, `BOT_TOKEN`, `STORAGE_CHANNEL` | .env فقط | لا تُعدَّل من اللوحة |

> التعديل من `/admin` → ⚙️ الإعدادات يسري **فورًا** بدون إعادة تشغيل،
> مع تحقق من صحة القيم الرقمية والمنطقية قبل الحفظ.

## 5) قرار التخزين

**التخزين = قناة/جروب تيليجرام خاص** (قرار المستخدم).

| الجانب | القرار |
|---|---|
| مكان الملف | منشور في قناة التخزين، يُحفظ `storage_message_id` |
| البيانات الوصفية | قاعدة البيانات + منشور "غلاف" JSON داخل القناة |
| التحميل للطلاب | `copy_message` من القناة (بلا إعادة رفع) |
| Google Drive | غير مفعَّل — يمكن إضافته لاحقًا كعمود `external_url` |

**المخاطر المعروفة:**
1. حد 20MB لكل ملف عبر Bot API الرسمي.
2. الملفات في تيليجرام ليست تحت سيطرتك الكاملة (حذف/حظر محتمل).
3. `file_id` صالح لبوت واحد فقط — لا يمكن مشاركته بين بوتات.

**التخفيف:** النسخ الاحتياطي للداتابيز دوري، ومنشورات الغلاف JSON تسمح بإعادة بناء الفهرس يدويًا.

## 7) معايير القبول لكل مرحلة

| المرحلة | المعيار القابل للقياس |
|---|---|
| **0** | وثيقة متطلبات + خريطة شاشات معتمدة *(هذا الملف)* |
| **1** | `pytest` أخضر على السكيم + تسجيل مستخدم + صلاحيات + نسخ احتياطي |
| **2** | رفع ملف يصل إلى قناة التخزين، يُراجَع، ويظهر ويُحمَّل |
| **3** | بحث يجد مصطلحًا داخل نص PDF وليس في العنوان فقط |
| **4** | نقاط تُمنح عند الموافقة + لوحة مشرف تعمل |
| **5** | قراءة ملف مصوّر عبر وكيل + بحث دلالي يجد ملفًا بلا تطابق كلمات + تقرير صحة + بث + PostgreSQL مُختبَر |
